# 路線設定欄位說明（`src/js/14_routes.js` 的 `ROUTES`）

每條路線是 `ROUTES` 裡的一個物件，物件名稱＝`key`。最完整的範例是範本裡的 `kenting`（海岸）與 `dapeng`（湖泊環線＋橋）。`r139` 是最早的路線，部分資料放在 `03_track.js`，**不要拿它當格式範例**。

## 座標與單位

- 公尺。賽道參數 `s`＝沿中心線距離（0 起），`d`＝橫向偏移，**正＝左、負＝右**。
- 台灣靠右行駛：右側（d<0）是路肩、標誌、海岸路線的海側。

## 基本資料

| 欄位 | 說明 |
|---|---|
| `key` | 小寫英數，與物件名稱相同 |
| `shield` | 路線牌文字（例 `'台26'`、`'139'`），1–4 字 |
| `title`／`sub`／`tag` | 選單標題、副標（「起點 → 終點」）、短標籤 |
| `desc` | 選單上的一段描述，寫實景特色 |
| `note` | 說明濃縮比例、哪些是編排（會顯示在選單） |
| `kmMax` | 路邊里程牌數量（1K…kmMax） |
| `attractS` | 選單背景展示車行駛的起點 s |

## 賽道形狀

| 欄位 | 說明 |
|---|---|
| `pieces` | `[[長度m, 轉角°], …]`，正＝左轉。程式會把曲率平滑，產生和緩彎道 |
| `heading0` | 起點朝向（度）。0＝朝南（+Z），90＝朝東，-90＝朝西，180＝朝北 |
| `sStart` | 起跑線位置，固定 90 |
| `sFinish` | 終點線位置 |
| `sEnd` | 賽道總長（終點後留 ≥300 m 緩衝）。必須 ≤ pieces 總長 |
| `hwFn(si)` | 回傳該處路面半寬（m）。一般 5.0；起點 6.2；山區窄路 4.7；街道 5.6 |

### 規則

- 彎道半徑＝長度 ÷（|轉角|×π/180）。**至少 35 m**；25–35 m 只用在真的有髮夾彎的地方。
- 每片長度 ≥ 40 m。
- 賽道不可繞回來太靠近自己：非相鄰路段至少相隔 80 m（`check-route.js` 會檢查）。
- 環線（例如湖、灣）：所有轉角加總約 360°，並讓終點回到起點附近，但兩端不要重疊。

### 從實景排出 pieces 的做法

1. 依查到的地圖描述，把路線拆成「直線段」與「彎道」，記下大致左右轉與角度。
2. 依濃縮比例縮短每段長度，**彎道角度維持原樣**（角度決定走向）。
3. 連續彎路段用短直線（40–80 m）夾著交替的 50–100° 彎道。
4. 跑 `check-route.js` 看「範圍約 X × Y km」是否合理，再看截圖修正。

## 段落與里程

```js
sections: [
  { s0: 0, s1: 1300, name: '南灣', sub: '恆春鎮・沙灘與核三廠', k0: 0, k1: 3 },
  { s0: 1300, s1: 2400, name: '墾丁大街', sub: '大尖山下的街市', k0: 3, k1: 5.5 }, …
]
```

- 必須從 0 開始、前後接續、最後一段 `s1 ≥ sFinish`。
- `k0`／`k1` 是對應的**實際里程**（公里），HUD 會依此換算。

另外兩個相關欄位：

- `landmarks`：`[{ s, name }]`，只做為參考列表。
- `realAlt`：`[[s, 實際海拔m], …]`，HUD 顯示用。

## 高程

`elev: [[s, 路面高度m], …]`，s 遞增、第一筆 s=0、最後一筆 ≥ sEnd。

- 遊戲高度不必等於真實海拔，但起伏趨勢要一致。
- 平均坡度不要超過 10%。
- `elevNoise`：在控制點之間加入的小起伏量（0＝完全照控制點；山路 0.8–1）。

## 兩側地形 `zkeys`

```js
zkeys: [{ s: 0, plL: 420, plR: 30, bkL: 0.05, bkR: -0.1, hs: 0, und: 0.6 }, …]
```

依 s 內插，第一筆 s=0、最後一筆 ≥ sEnd。

| 欄位 | 說明 |
|---|---|
| `plL`／`plR` | 左／右側「台地」半寬（m）：超過這個距離後地形開始往下掉。海岸的海側用 30–60，平原用 400+，山稜用 40–150 |
| `bkL`／`bkR` | 左／右邊坡偏向（-1～1）：正＝高於路面（山壁、挖方），負＝低於路面（下邊坡） |
| `hs` | 山腰路強度（0～1）：兩側上下邊坡沿路交替，適合沿山壁開的路 |
| `und` | 地表小起伏幅度（平原 0.3、丘陵 2–4） |

其他整條路共用的地形參數：

| 欄位 | 說明 |
|---|---|
| `slopeL`／`slopeR` | 台地外下降的陡度（0.1 平緩～0.5 陡） |
| `gully` | 山溝雕刻強度（0 平滑～1 明顯） |
| `plain(x, z)` | 遠方基準地形高度函式（世界座標）。可用 `fbm`、`ridged`、`vnoise`、`smooth`、`lerp`、`this.*`（在 `init()` 預先算好） |
| `init()` | 路線建好後呼叫一次，可用 `trackAt(s, {})` 取得賽道上的點，計算 `plain` 需要的參考值 |
| `mount` | 天空遠山剪影 `[遠層, 中層, 近層強度, 方位旋轉(弧度)]`。山在東側就 `[1,1,1,0]`，西側就 `[…, PI]` |

## 水域

| 欄位 | 說明 |
|---|---|
| `sea` | 海平面高度。沒有水就 `-999` |
| `seaMin` | 低於這個高度不種樹、不蓋房（通常 0.7） |
| `water` | `{ deep: [r,g,b,1], shallow: [r,g,b,淺水深度m], beach: 0～1 }`。熱帶海：deep `[0.008,0.07,0.19,1]`、shallow `[0.04,0.36,0.36,5]`；潟湖：deep `[0.02,0.09,0.11,1]`、shallow `[0.1,0.2,0.16,2.5]` |
| `soil` | 土色倍率 `[r,g,b]`。紅土 `[1,1,1]`；沙地 `[2.7,6.2,9]`；灰沙 `[1.5,3.6,5.4]` |
| `ponds` | 0～1，平原遠景中魚塭的比例 |
| `plainPatch` | 0～1，遠方平原是否畫成田區拼布（海岸設 0） |
| `bridge(s)` | 回傳 0～1，1＝該處是橋，地形不墊高。例：`bridge(s) { return smooth(2640, 2720, s) * (1 - smooth(3380, 3460, s)); }` |

## 土地利用與植被 `zones`

```js
zones: [{ s0: -100, s1: 1300, id: 'nanwan', w: [0.35,0,0,0,0.25,0.15,0,0.25,0,0,0,0],
          row: { sp: 14, ty: 'coconut', p: 0.75 }, dens: 0.7,
          mix: [['casuarina',0.35],['broad',0.3],['coconut',0.15],['pandanus',0.2]], palm: 'coconut', poles: 1 }, …]
```

第一段 `s0 ≤ 0`，最後一段 `s1 ≥ sEnd`，前後接續。`id` 每段唯一。

### `w`：12 個權重，總和 1

依序為：

| 序 | 類型 | 呈現 |
|---|---|---|
| 0 | 森林 | 依 `mix` 種樹 |
| 1 | 茶園 | 茶樹列 |
| 2 | 鳳梨田 | 鳳梨列 |
| 3 | 果園 | 荔枝／龍眼樹格 |
| 4 | 草地／牧場 | 草地 |
| 5 | 檳榔 | 依 `palm`（預設檳榔，可改 `'coconut'`）種成格狀 |
| 6 | 竹林 | 竹叢 |
| 7 | 聚落 | 鋪面、農舍、鐵皮屋 |
| 8 | 落羽松 | 落羽松 |
| 9 | 菜園／魚塭 | 路線的 `ponds` > 0 時呈現為魚塭 |
| 10 | 沙地 | 沙灘 |
| 11 | 魚塭 | 同 9 |

斜坡 > 0.38 或台地外一律變森林。

### 其他欄位

- `mix`：森林的樹種比例。
- `row`：行道樹。
  - `sp`：間距（m）。
  - `ty`：樹種名、`'mix'` 或樹種比例陣列。
  - `p`：出現機率；不要行道樹就設 0、`sp` 設 999。
- `dens`：森林密度（0.2～1.1）。
- 可用樹種：`acacia`（相思樹）、`broad`（闊葉樹）、`terminalia`（小葉欖仁）、`lychee`（荔枝／龍眼，也可當紅樹林灌叢）、`betel`（檳榔）、`bamboo`（竹）、`cypress`（落羽松）、`shrub`（灌木）、`banana`（香蕉）、`coconut`（椰子）、`pandanus`（林投）、`casuarina`（木麻黃）。

### 選用旗標

| 旗標 | 作用 |
|---|---|
| `town: 1` | 路肩鋪面、矮緣石 |
| `dash: 1` | 直線段畫中央黃虛線 |
| `poles: 1` | 電線桿 |
| `nofarm: 1` | 不蓋農舍 |
| `nograss: 1` | 路邊不長草 |
| `rail: 1/2/3` | 強制護欄型式：1＝鋼板護欄、2＝混凝土護牆、3＝緣石 |
| `pasture`／`pastureP` | 草地上零星散生的樹種與機率 |

### `landOverride(s, left, ad, x, z)`

回傳 `LU.*` 強制某範圍的土地利用，其他回傳 -1。`left`＝是否在左側，`ad`＝距中心線距離。例：海側沙灘 `if (!left && ad > 10) return LU.SAND;`

## 街道、路口、路面標記

| 欄位 | 說明 |
|---|---|
| `streets` | `[[s0, s1], …]` 兩側蓋透天厝街屋 |
| `streetSkip(s, sg)` | 回傳 true 跳過某處（`sg`：1 左、-1 右） |
| `junctions` | `[{ s, w: 路寬, len: 長度, sides: [1, -1] }]` 交叉路口（橫向道路）。路口附近不放事件 |
| `decal40` | 路面噴「40」的位置 |
| `zebras` | 斑馬線位置 |
| `fog` | `[s0, s1]` 起霧段（選用） |

## 地標、標誌、門架

- `plan(add, tr, R)`：放地標，見 `landmarks.md`。
- `signs()`：回傳 `[[s, 貼圖層, uv, 寬, 高], …]`，立在右側路邊、面向來車。觀光指示用 `PL.BROWN2` 加 `brown2(i)`；要新的文字需新增貼圖層，見 `landmarks.md`。
- `gates`：`[{ s, plaque, banner }]`。
  - `plaque: -1`＝鋼構門架；`0..3`＝牌樓，使用匾額貼圖的第幾格。
  - `banner: 0`＝起點布條、`1`＝終點布條。
  - 通常放兩個：s=116（起點）、s=sFinish（終點）。

## 自動產生（不用設定）

修復愛心兩顆、防撞緩衝車、油罐車漏油都由 `17_events.js` 的 `planHazards()`，在全程約 30／46／62／80% 處挑較直的路段放置。彎道警告標誌、急彎導標、里程牌、速限、路面「慢」字由 `11_props.js`／`06_road.js` 依曲率自動放置。
