# 台灣房車賽

三條路線（139 稜線、墾丁 台26、大鵬灣 環灣）的 3D 房車賽車遊戲。純 WebGL2，場景、車輛、貼圖、音效全部由程式即時生成，沒有任何外部素材或套件。

## 怎麼玩

| 玩法 | 做法 |
|---|---|
| 單機 | 直接用瀏覽器打開 `public/index.html` |
| 線上對戰 | 安裝 [Node.js](https://nodejs.org)（16 以上，免費）→ 執行 `node server.js`（Windows 可雙擊 `啟動伺服器.bat`）→ 用瀏覽器開它印出的網址 |

### 線上對戰（最多 8 人）

1. 一個人當主機，執行 `node server.js`。
2. 所有人用瀏覽器開主機的網址：
   - 同一個 Wi-Fi／區域網路：用終端機印出的「區域網路」網址（例如 `http://192.168.1.23:8139`）。
   - 不同網路：主機需要讓外面連得進來，擇一即可：路由器把 8139 埠轉到主機；或用免費的通道工具（如 Cloudflare Tunnel 的 quick tunnel、ngrok 免費方案）把 `localhost:8139` 對外；或把整個資料夾部署到任何能跑 Node.js 的主機。透過 https 開啟時，遊戲會自動改用 wss。
3. 選單「模式」選「線上對戰」→ 輸入暱稱 → 房號留空按「連線」會開新房間，把顯示的房號告訴朋友；朋友輸入同一個房號按「連線」。
4. 房主選好路線與時段後按「出發」，所有人載入完成就會一起倒數。

## 毀損

撞擊 1–8 次只影響外觀；第 9 次接近全毀、動力下降；第 10 次拋錨，車主會下車站在一旁。抵達終點前的剩餘路程顯示在左上角。

## 路上事件

- 粉紅愛心（每條路線三顆，放在路中央）：經過時撞擊次數歸零。
- 高速公路防撞緩衝車：沒閃過會翻兩圈落地，速度降到 10–20 km/h。
- 油罐車拋錨漏油：壓到油漬會打轉，速度降到 10–20 km/h。
- 139 路線的 19K–23K 連續彎會起霧；各彎道前有警告標誌。

## 操作

- 鍵盤：W/↑ 油門、S/↓ 煞車與倒車、A D/← → 轉向、空白鍵手煞車、C 視角、R 復位、P 暫停、M 靜音、H 隱藏介面；滑鼠拖曳環視。
- 觸控：左半邊左右滑動轉向，右側踏板煞車／油門（預設自動油門）。
- 手把：左搖桿轉向、RT 油門、LT 煞車、A 手煞車。

## 手機、平板

- 手機建議橫放（直式也能玩，選單會提醒）；平板直式、橫式都可以。
- 選單裡的「全螢幕」按鈕可以讓畫面更大（Android、iPad）；iPhone 請用 Safari 的「分享」→「加入主畫面」，從主畫面開啟就是全螢幕。
- 比賽中螢幕不會自動休眠；輸入暱稱、房號不會讓頁面自動放大。
- 需要 WebGL2：iPhone／iPad 請用 iOS 15 以上，Android 請用較新的 Chrome。

## 資安

見 [SECURITY.md](SECURITY.md)：沒有帳號、不收集個資；線上對戰伺服器有同源檢查、流量限制、輸入清理與人數上限。

## 修改與重新建置

原始碼在 `src/`。改完後執行：

```
node build.js        # 合併成 public/index.html
node server.js       # 開伺服器測試（或直接開 public/index.html）
```

`build.js` 只是把 `src/js/*.js` 依檔名順序串起來、包進一個 IIFE，再塞進 `src/index.html` 的 `/*__JS__*/` 位置。沒有打包工具、沒有相依套件。

程式結構與修改指引見 `AGENTS.md`。
